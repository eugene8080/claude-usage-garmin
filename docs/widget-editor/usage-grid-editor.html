Usage Grid - widget editor

Design the 2×1 usage grid widget: 7 rows (Claude 5H / 1W / FA, Codex 1W, Cursor PL / AU / AP) × 10 boxes, each 10 %. The box a percentage lands in is shaded by how far into its band it is and carries the number; the right column is each row's reset time. Everything here is drawn natively by the widget - plain boxes, colours, Android's own fonts, rounded corners, and fixed drawables for the gradients, gloss and bevel - no picture of the widget. Sizes, text included, are dp at the zoom below. Theme sets the colours and effects at once; editing one switches to Custom. Click a section's heading to fold it. Fonts the widget can use
A home-screen widget can't load its own fonts unless it is drawn as a picture, so it uses Android's built-in families, in three weights: Normal, Medium, Bold. monospace is drawn with Android's own font file; the other samples use the same typefaces from Google Fonts. Brand phones can swap the default sans: on ColorOS (Oppo) sans-serif may come out in OPPO Sans.

Halo (native glow)
A widget can't blur, so the glow is a translucent ring around each lit box (one or two rings, softer outside). It lives in the gap between boxes, so it is at most half the gap wide.
